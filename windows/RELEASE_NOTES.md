# Compositor for Windows — 0.1.0 Preview 1

A Windows image editor for layered artwork, comics, pixel art and Glitch Temple treatments, with a ChatGPT collaborator that can work in the same document as you.

Download **Compositor-0.1.0-preview.1-Windows-x64-Setup.exe** for Desktop and Start Menu shortcuts. For a portable copy, extract **Compositor-0.1.0-preview.1-Windows-x64-Portable.zip** and open `Compositor.exe` inside the extracted folder. No Python, Node or terminal setup is required.

This preview runs on 64-bit Windows 10 or later. Its executables are unsigned, so Windows may show an unknown-publisher warning. It includes:

- Editable layers, masks, selections, text, shapes, adjustments, painting and image export.
- Pixel canvases, hard-edge pencil tools, palette conversion and whole-number enlargement.
- Tai Mei's Glitch Temple effects, retained source images and recipes, and GIF/MP4 animation export.
- Project pages, reusable style direction and named character references for comics and illustrated books.
- ChatGPT sign-in through the official Codex runtime, with automatic tool connection. Subscription image generation depends on the account; API providers remain a separate choice.
- The same editor tools for external MCP clients, without mouse or keyboard automation.

The release remains under active development. PSD import does not preserve every Photoshop feature; check conversion notes. Automatic subject selection, perspective distortion, independently transformed masks and GPU rendering are not yet implemented. [The module map](https://github.com/almosthuman-ai/Compositor/blob/windows-studio/module-manifest.md) records the current boundaries.

Original Compositor by **Robbie Tilton**. Glitch Temple by **Tai Mei**. Windows edition by **Legion and contributors**. Their attribution and applicable licenses ship with the app. The separate animation encoder includes its complete corresponding source archive and build instructions.
